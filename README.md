# FocusFlow Pomodoro

A fresh, beginner-friendly desktop Pomodoro timer built with Python and Tkinter.

## Features
- 25-minute focus timer, 5-minute short break, and 15-minute long break
- Start, pause, and reset controls
- Automatic break suggestions after a focus session
- Progress bar and completed-session counter
- Simple task list with add/remove controls
- Tasks and completed-session count saved locally in `focusflow_data.json`
- Dark desktop interface

## Requirements
- Python 3.10+
- Tkinter (included with most standard Windows Python installations)

No third-party packages are required.

## Run on Windows
1. Extract the ZIP file.
2. Open the extracted `FocusFlow_Pomodoro` folder in VS Code.
3. Open Terminal in VS Code.
4. Run:

```powershell
python main.py
```

If `python` is not recognized, try `py main.py`.

## Notes
Your tasks and session count are saved locally beside `main.py`. The app does not upload data or require an account.
